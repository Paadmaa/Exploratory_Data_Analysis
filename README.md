## 🛠️ Getting Started

Clone the repository and navigate into the folder:

```bash
git clone https://github.com/Paadmaa/Data_Analysis_Projects.git
cd Data_Analysis_Projects
```

---

## 📦 Dependencies

Create a virtual environment and install core requirements:

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Core libraries include pandas, NumPy, matplotlib, seaborn, scikit-learn, BeautifulSoup4, and plotly.

---

## 🚀 Usage

1. Enter a project folder:  
   ```bash
   cd <Project_Folder>
   ```
2. Open the Jupyter notebook or run the analysis script:  
   ```bash
   jupyter notebook
   # or
   python analysis.py
   ```
3. Refer to each folder’s README for dataset links and detailed steps.
